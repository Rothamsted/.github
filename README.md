# .github

Organisation-level configuration for [RothResearch](https://github.com/RothResearch).

| Path | What it is |
|---|---|
| `profile/README.md` | The landing page shown at [github.com/RothResearch](https://github.com/RothResearch) |
| `profile/logo-lockup.png` | Rothamsted Research logo, light backgrounds |
| `profile/logo-lockup-dark.png` | Same lockup with a white wordmark, for GitHub's dark theme |
| `profile/avatar-roundel.png` | 460×460 roundel used as the organisation avatar |

This repository must stay **public** for the profile README to render. It holds no research code.

Files placed here also act as organisation-wide defaults — a `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md` or `.github/ISSUE_TEMPLATE/` here applies to every repository in the organisation that does not define its own.

Logo files are © Rothamsted Research and subject to institutional brand guidelines.
